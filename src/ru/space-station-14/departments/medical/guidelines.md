# Руководство по PR

## Создание медицинского PR

К медицинским PR относится всё, что охватывается документом Медицинской рабочей группы. PR, затрагивающие BodySystem и связанные компоненты, ход раунда Медицинского отдела и реагенты, являются медицинскими PR и должны соответствовать перечисленным здесь рекомендациям по PR. 

Медицинские PR должны в своём описании или заголовке указывать, предназначено ли это изменение для текущей upstream-медицинской системы или для дебодизации/Диско-Меда (см. [Документ Медицинской рабочей группы](medical-workgroup.md)). PR без чёткого намерения может быть закрыт, если он не следует рекомендациям ни для текущей upstream-медицины, ни для Диско-Меда. 

По любым дополнительным вопросам обращайтесь к медицинской рабочей группе через Discord-сервер SS14.

### PR для текущей медицины
PR для текущей медицины обычно должны быть нацелены на исправление или перебалансировку текущего поведения. Такие PR должны обосновывать своё существование; текущая медицинская система крайне несовершенна, поэтому часть описания PR должна объяснять, почему это следует объединить, а не ждать лучшей реализации медицины. PR с микробалансировкой будут закрываться на усмотрение рабочей группы. Обычные обоснования могут включать: исправления ошибок, эксплойты, крайне несбалансированное/мета-поведение или небольшие дополнения, которые не сильно меняют ключевые системы. 

Кроме того, такие PR не могут и никогда не должны обращать дебодизацию вспять или жёстко прописывать поведение системы тела в другую систему. Если PR не может соответствовать этим рекомендациям и не может быть изменён, чтобы им соответствовать, он должен быть переработан в соответствии с рекомендациями Диско-Меда или закрыт. 

### PR для Диско-Меда/дебодизации
PR, предназначенный для дебодизации/Диско-Меда, должен соответствовать [Документу по дизайну медицины](../medical.md). Ожидается, что PR для Диско-Меда и дебодизации будут более высокого качества кода и будут подвергаться более тщательной проверке. Такие PR должны чётко объяснять в своём описании, как это продвигает медицинскую систему или продвигает разрушение/реконструкцию BodySystem. PR для Диско-Меда и дебодизации не должны идти на компромиссы в коде. Если PR вынужден идти на компромиссы в коде, то в его описании должно быть объяснено как то, каковы эти компромиссы, так и то, что нужно для их устранения, а также эти компромиссы в коде должны быть помечены TODO.

PR, которые приходится разбивать на несколько частей, могут требовать документа по дизайну; это особенно верно, если выполнено любое из следующих условий:
- PR не охвачен предыдущим документом по дизайну
- PR не был предварительно одобрен членом медицинской рабочей группы
- PR отклоняется от Документа по дизайну медицины или Документа Медицинской рабочей группы
- PR настолько масштабен, что его, возможно, потребуется разделить между несколькими участниками
- PR требует, чтобы сначала были переработаны несколько других систем

По дополнительным вопросам о дебодизации и Диско-Меде смотрите: [Документ Медицинской рабочей группы](medical-workgroup.md)

### PR для Оффмеда
PR для Оффмеда не следует объединять в master, так как Оффмед является тестовой веткой. Вместо этого их следует объединять напрямую в саму ветку Оффмед. Поскольку Оффмед является веткой тестирования функций, полностью контролируемой медицинской рабочей группой, любой PR, предназначенный для Оффмеда, может быть закрыт по любой причине.
