# Аббревиатуры и номенклатура

| Сокращение               | Значение                                                                                                             |
|:------------------------ |:------------------------------------------------------------------------------------------------------------------- |
| SS14                     | Space Station 14. Ремейк Space Station 13 (SS13).                                                                   |
| BYOND                    | Игровой движок для SS13.                                                                                            |
| RobustToolbox, Engine    | Игровой движок SS14. (Считайте его BYOND).                                                                          |
| Content, Content Pack    | «Игра», работающая на RobustToolbox. (Считайте её SS13).                                                             |
| CVar                     | Convar/Console Variable. Настраиваемое значение, которое можно изменить в файлах конфигурации или через консоль.    |
| .yml, YAML               | YAML Ain't Markup Language. Используется для определения прототипов.                                                |
| .toml, TOML              | Tom's Obvious Minimal Language. Как YAML, но для конфигурации.                                                      |
| ECS                      | Entity Component System                                                                                             |
| IoC                      | [Инверсия управления](../../robust-toolbox/ioc.md)                                                                  |
| .dmi, DMI                | Формат файлов спрайтов BYOND/SS13. Для наших нужд конвертируется в RSI.                                             |
| .rsi, RSI                | Robust Station Images. «Файловый» формат изображений SS14 (на самом деле папка).                                    |
| PVS                      | Potentially Visible Set. Не позволяет серверу отправлять клиентам сущности вне зоны видимости.                      |
| PJB, PJB3005             | Руководитель проекта. Какого чёрта моё имя здесь делает?                                                            |
| VSC, VSCode              | Visual Studio Code. Не то же самое, что VS.                                                                         |
| VS                       | Visual Studio Community 2017/19. Не то же самое, что VSC. IDE для тех, кто не может получить лицензию Rider.       |
| Rider                    | [Кроссплатформенная IDE для C#.](https://www.jetbrains.com/rider/) (Можно получить бесплатно для некоммерческого использования). |
| Watchdog                 | SS14 Server Watchdog. Используется для логирования, обновления и общего управления выделенным сервером.             |
| Lidgren                  | Библиотека для работы с сетью.                                                                                      |
| Box2D                    | Основа (сильно изменённой) физической системы SS14.                                                                 |
| Avalonia                 | UI-фреймворк, используемый для лаунчера.                                                                            |
| Postgres, SQLite         | Базы данных.                                                                                                        |
| EntityUid                | Уникальный идентификатор сущности                                                                                   |
