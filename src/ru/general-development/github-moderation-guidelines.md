# Правила модерации Github

Этот документ разъясняет правила модерации Github применительно к Кодексу поведения проекта. Модераторы Github должны придерживаться этих правил как базового уровня для действий, предпринимаемых в репозитории Github, но могут отступать от них, если считают, что это в интересах сообщества. 

Примечание: если вы считаете, что эти правила не были соблюдены или были нарушены без веской причины, рекомендуем связаться с персоналом через [Discord](https://discord.ss14.io/) или [форумы](https://forum.spacestation14.com/), обжаловать ваш бан в Github [на форумах](https://forum.spacestation14.com/c/ban-appeals/appeals-github/38), либо подать [жалобу на персонал](https://forum.spacestation14.com/t/staff-complaint-instructions-and-info/31). Неправильное применение [Кодекса поведения](https://github.com/space-wizards/space-station-14/blob/master/CODE_OF_CONDUCT.md) не повлечёт дисциплинарных мер для персонала, если оно было совершено добросовестно, и оставлено для крайних случаев, когда добросовестность отсутствует.

## Модерационные действия

### Перманентные баны

Контент, нарушающий примеры, перечисленные в пункте «**Be careful in the words that you choose.**» [Кодекса поведения](https://github.com/space-wizards/space-station-14/blob/master/CODE_OF_CONDUCT.md), приведёт к немедленному перманентному бану без права обжалования и жалобе в организацию Github.

Это также может применяться, если нарушающий контент находится за пределами Github Space Station 14, например на сервере Wizden в Discord, форумах или где-либо ещё, по усмотрению модератора Github. PR, созданные нарушившим пользователем, должны быть закрыты, хотя их содержимое может быть подхвачено другим участником и повторно использовано в новом PR, если это позволяет лицензия.

### Другие действия

Как указано в разделе «**On Community Moderation**», контент/комментарии, создающие недоброжелательную атмосферу для проекта, могут повлечь модерационные действия. В распоряжении модераторов Github есть следующие действия:
- Скрытие комментариев.
  - Предпочтительно использовать для комментариев, которые не по теме или в остальном безобидны, но не вносят вклада в обсуждение. Такие комментарии следует помечать как «Off-Topic» или «Spam»; хотя интерфейс предоставляет и другие причины для скрытия комментария, они лучше подходят для случаев ниже.
- Удаление контента и выдача 24-часового бана в Github.
  - Для контента/комментариев, поданных в неконструктивной манере (примеры перечислены в [Кодексе поведения](https://github.com/space-wizards/space-station-14/blob/master/CODE_OF_CONDUCT.md)), контент может быть удалён, даже если он отчасти конструктивен. Если это необходимо, нарушившему пользователю следует выдать 24-часовой бан в Github. Хотя бан иногда может показаться чрезмерным, это единственный способ напрямую сообщить пользователю, что против него были приняты меры.
- Длительные баны в Github.
  - Если пользователь неоднократно нарушает Кодекс поведения, может быть оправдан бан в Github на более длительный срок. Срок должен составлять от 7 дней до 1 месяца, по усмотрению модератора Github. Всё более длительное должно быть баном только с правом обжалования.
- Баны только с правом обжалования.
  - Бан только с правом обжалования может быть выдан вместо длительного бана. Такие баны можно [обжаловать только на форумах](https://forum.spacestation14.com/c/ban-appeals/appeals-github/38), не раньше чем через 6 месяцев после выдачи бана.
 
Из-за ограничений инструментов модерации Github затронутый пользователь может получить только уведомление о том, что против него были приняты меры, а не о сроке или причине. Это возможно только через опцию «Block» в нарушающем комментарии Github, которую следует использовать, если это возможно. Если затронутый пользователь спросит о своём бане через один из официальных каналов, ему должны сообщить причину.
