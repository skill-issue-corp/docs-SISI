# Репозиторий Discord Rich Presence

## Пользовательские ассеты

Если вы хотите отображать пользовательские ассеты, например иконку сервера, в Rich Presence, мы должны загрузить их в ассеты приложения Discord. Подробности см. в [этом репозитории](https://github.com/space-wizards/asset-dump/tree/master/discord-app-assets).
