# Каталог пользовательских данных
Каталог пользовательских данных используется и клиентом, и сервером для хранения постоянных изменяемых данных.

Каталог пользовательских данных может быть доступен для чтения и записи контентом через `IResourceManager.UserData`. Он также используется некоторыми другими вещами, например сохранением файлов конфигурации на клиенте.

## Сервер

Каталог выбирается в таком порядке:
1. Если при запуске сервера в качестве аргумента передан `--data-dir`, например `./Robust.Server --data-dir /foo`, используется переданный каталог.
2. Используется каталог `data` рядом с исполняемым файлом сервера.

## Клиент

Каталог выбирается в таком порядке:
1. Если при запуске клиента в качестве аргумента передан `--self-contained`, используется каталог `user_data` рядом с исполняемым файлом клиента.
2. Каталог данных, выбранный как глобальное для пользователя, подходящее для ОС расположение:
    * `$UserDataDirectoryName` по умолчанию равен `Space Station 14`, но может быть переопределён не-лаунчерными играми Robust путём указания `GameControllerOptions.UserDataDirectoryName`.
    * Windows: `%APPDATA%/$UserDataDirectoryName/data`.
    * macOS: `~/Library/Application Support/$UserDataDirectoryName/data`
    * Linux: `$XDG_DATA_HOME/$UserDataDirectoryName/data`, `XDG_DATA_HOME` предполагается равным `~/.local/share`, если не задан.

При подключении к серверам через лаунчер в настоящее время нет никакой изоляции хранилища между серверами. Не храните какие-либо конфиденциальные данные сервера в клиентских пользовательских данных, так как они могут быть доступны любому другому серверу.

## Интеграционные тесты

В интеграционных тестах (и клиентских, и серверных) каталог пользовательских данных — это поддельная файловая система в памяти, призванная приблизительно эмулировать поведение реального диска. Она никак не сохраняется.
