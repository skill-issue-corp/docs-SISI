# Контексты вызова
`IInvocationContext` представляет собой контекст, в котором toolshed выполняет команды; он предоставляет функции оболочки, чтение/запись переменных, проверку разрешений и вывод ошибок.

## Рекомендации
- Если ваша команда временно задаёт переменную для выполнения блока, следует реализовать контекст-обёртку, который предоставляет эту переменную внутри себя, вместо того чтобы задавать переменную в существующем контексте. Это предотвращает утечку переменных.
- CheckInvokable не следует переопределять без ОЧЕНЬ веской причины, так как это граница безопасности.
- Не игнорируйте ошибки: если у вас нет способа корректно обработать ошибку, её, скорее всего, следует бросить как исключение, чтобы кто-нибудь её заметил.
