# Команды
Это не список команд, им являются подстраницы этой страницы.
## Обозначения
В страницах команд есть некоторые обозначения, которые стоит знать.
### Заголовки разделов.
Ниже приведены наиболее распространённые заголовки разделов и их назначение:
<table>
<thead>
  <tr>
    <th>Название</th>
    <th>Описание</th>
  </tr>
</thead>
<tbody>
  <tr>
    <td>Источники</td>
    <td>Команды, которые создают список некоторого интересующего значения, который затем можно отфильтровать и обработать.</td>
  </tr>
  <tr>
    <td>Фильтры</td>
    <td>Команды, которые фильтруют входные данные, то есть удаляют ненужные значения.</td>
  </tr>
  <tr>
    <td>Преобразователи</td>
    <td>Команды, которые преобразуют входные данные в другой тип.</td>
  </tr>
  <tr>
    <td>Мутаторы</td>
    <td>Команды, которые каким-либо образом изменяют входные данные.</td>
  </tr>
