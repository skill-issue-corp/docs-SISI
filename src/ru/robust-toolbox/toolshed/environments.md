# Окружения
Основным способом управления тем, какие команды доступны в Toolshed (что определяет всё, от разбора до потока выполнения), является `ToolshedEnvironment`. Окружение по умолчанию находится в `ToolshedManager.DefaultEnvironment` и содержит все команды с применённым атрибутом `[Toolshedcommand]`.

## Рекомендации
- Кэшируйте свои окружения: `ToolshedEnvironment` чрезвычайно дорого создавать, и по возможности его не следует создавать более одного раза на каждую систему, которая его использует.
- Избегайте использования окружения по умолчанию для неотладочных вещей; создавайте собственное окружение для своих систем.
- Не злоупотребляйте рефлексией для получения типов команд, помеченных как internal или private, **внутренние API гарантированно нестабильны.**
