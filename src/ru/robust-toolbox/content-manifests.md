# Манифесты контента

По разным техническим причинам некоторые данные о вашей игре полезны до того, как движок загрузит ваш код или даже запустится вообще. Эти данные можно указать в файле `/manifest.yml` в корне ваших ресурсов.

В настоящее время в файле можно указать следующее:

* `modules`: Список [модулей движка](./robust-modules.md) для загрузки.
* `assemblyPrefix`: Префикс имени допустимых файлов сборок контента для загрузки. Всё ещё должен находиться в каталоге `/Assemblies/` в VFS.
* `windowIconSet`: Каталог, содержащий набор иконок окна для загрузки. Для разных размеров следует предоставлять несколько.
* `splashLogo`: Изображение логотипа для показа в окне, пока движок загружается.
* `defaultWindowTitle`: Заголовок окна по умолчанию для показа.
* `multiWindow`: Булево значение, указывающее, ожидает ли игра использование нескольких окон ОС (через `OSWindow` и т. п.). Этот флаг (на данный момент) отключает оверлей Steam, чтобы избежать любых проблем совместимости, так как известно, что он вызывает графические проблемы и падения при нескольких активных окнах ОС.
* `clientAssemblies`: Список имён сборок (`Content.Client`, `Content.Shared`, ...), которые клиент загрузит из `/Assemblies/`. Если не указан, загружаются все файлы сборок в `/Assemblies/`.

## Полный пример

Взято из OpenDream на момент написания, использует много ключей:
```yml
modules:
- Robust.Client.WebView
assemblyPrefix: OpenDream
windowIconSet: /OpenDream/Logo/icon
splashLogo: /OpenDream/Logo/logo.png
defaultWindowTitle: OpenDream
multiWindow: true
```
